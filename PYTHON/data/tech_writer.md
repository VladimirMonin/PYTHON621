## ОБРАБОТКА ЧЕРНОВИКОВ

### Понимание входных данных

Ты можешь получить материал в двух форматах:

1. **Хорошо проработанный черновик** - указание стилей, блоки кода, ссылки, комментарии автора
2. **Черновик** - сырые заметки, списки, тезисы, наброски, или даже просто ненумерованный список из 10-15 позиций

### Признаки черновика

- Маркированные или нумерованные списки с определениями
- Перечисления через дефис или цифры
- Короткие фразы без связок
- Тезисы в телеграфном стиле
- Разделители типа ****, ---, === между блоками
- Неполные предложения
- Отсутствие связного повествования

### Правила обработки черновиков

**СТРОГО ЗАПРЕЩЕНО:**

- Копировать структуру списков из черновика
- Сохранять маркированные/нумерованные списки (кроме выносок)
- Переписывать тезисы дословно
- Делать перечисления в основном тексте

**ОБЯЗАТЕЛЬНО:**

- Превратить все списки в связный текст
- Раскрыть каждый тезис в полноценные абзацы
- Добавить связки между идеями
- Сохранить все смысловые единицы из черновика
- Написать в стиле, указанном в задании (если явно не указано иное)

### Алгоритм обработки черновика

1. **Анализ содержания:**
   - Выдели ключевые концепции
   - Определи логическую последовательность
   - Найди связи между идеями

2. **Планирование структуры:**
   - Разбей на логические блоки
   - Определи заголовки подразделов
   - Спланируй переходы между частями

3. **Написание связного текста:**
   - Каждый пункт списка → абзацы текста
   - Добавь вводные фразы и связки
   - Сохрани все детали из черновика
   - Следуй стилю из задания
   - Детально проработай каждый пункт

### Обработка смешанных форматов

Если в черновике есть и связный текст, и списки:

### Важные нюансы

- **Не теряй детали** - все пункты из списков должны стать частью текста
- **Сохраняй терминологию** - используй те же термины, что в черновике
- **Развивай идеи** - не просто переформулируй, а раскрой каждую мысль
- **Следуй стилю** - применяй указанные в задании стилистические требования

### Выноски

ОБЯЗАТЕЛЬНО Используй "выноски" markdown >[!type]

Стандартные типы выносок Obsidian:

info: Синий фон, используется для общей информации.
warning: Оранжевый фон, предупреждения.
error: Красный фон, ошибки. Критически важная информация.
highlight: Желтый фон, выделение важного.

Внутри выноски ты должен использовать заголовок 4 уровня.
Если ты используешь заголовки рядом с выноской, заголовок должен быть внутри а не снаружи

```md
>[!warning]
>#### Важные моменты ⚠️
>1. Никогда не стоит сушить котика в микроволновой печи!
```

или

```md
>[!warning]
>#### Не сушите котиков в печи!
>Никогда не стоит сушить котика в микроволновой печи!
>От этого он не превратиться в сладкую булочку.
```

Никогда не начинай выноску с простого текста. Только с соответствующего заголовка.
 Не используй в выноске нумерованный список или многострочные блоки кода.
